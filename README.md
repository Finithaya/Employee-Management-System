👨‍💼 Employee Management System

A web-based application developed using PHP and Laravel to manage employee records, attendance, and leave details efficiently.

✨ Features

- 👤 Manage employee records
- 📅 Track employee attendance
- 📝 Manage leave requests
- 🔍 View and manage employee details
- ⚠️ Prevent duplicate attendance and leave entries for the same date

🛠️ Technologies Used

- 🐘 PHP
- 🚀 Laravel
- 🗄️ MySQL
- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript
- 🅱️ Bootstrap
